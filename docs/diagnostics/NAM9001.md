# NAM9001: Bundled analyzer is required

Severity: error. The build found no NAM analyzer in the package, so the ownership rules would not run.

## Wrong

```xml
<ItemGroup>
  <PackageReference Include="Supprocom.NativeAllocationManagement" Version="0.3.2" />
</ItemGroup>

<Target Name="DropAnalyzers" BeforeTargets="NAMVerifyAnalyzerPresence">
  <ItemGroup>
    <Analyzer Remove="@(Analyzer)" /> <!-- NAM9001: no analyzer left -->
  </ItemGroup>
</Target>
```

## Right

```xml
<ItemGroup>
  <PackageReference Include="Supprocom.NativeAllocationManagement" Version="0.3.2" />
</ItemGroup>
```

The check runs before compilation, in the package's build targets. Restore the package with its analyzer assets and do not remove them from the project.
