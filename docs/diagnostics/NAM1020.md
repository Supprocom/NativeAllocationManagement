# NAM1020: Scoped native storage is not recycled on every exit

Severity: warning. Scoped storage leaves its region without `RecycleScoped` on every path.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        scoped ArenaLease<int> values = arena.ScratchScoped<int>(4, 0);
        values.Access(static view => view[0] = 1);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        try
        {
            scoped ArenaLease<int> values = arena.ScratchScoped<int>(4, 0);
            values.Access(static view => view[0] = 1);
        }
        finally
        {
            arena.RecycleScoped();
        }
    }
}
```

Call `RecycleScoped` on the same owner in `finally`, so an exception also recycles.
