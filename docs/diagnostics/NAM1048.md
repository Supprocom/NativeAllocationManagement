# NAM1048: Concurrent lease state cannot contain native ownership

Severity: error. State passed to a concurrent lease's `Process` contains a NAM owner (pool, arena, builder, lease or transfer), directly or nested.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int total = values.Process(1, default(PoolState), static (view, state) => view[0]); // NAM1048: state holds a pool

public readonly record struct PoolState(NativeConcurrentPool<int> Pool);
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int total = values.Process(1, new ProcessState(3), static (view, state) => view[0] + state.Offset);

public readonly record struct ProcessState(int Offset);
```

A field typed `object`, `dynamic`, an interface, a delegate, a pointer or a type parameter also counts, at any depth. Constructing the state from a live owner reports [NAM1001](NAM1001.md) as well.
Related: [NAM1047](NAM1047.md), [NAM1049](NAM1049.md).
