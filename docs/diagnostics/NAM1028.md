# NAM1028: Native builder ownership cannot be copied

Severity: error. A `NativeBuilder<T>` is copied to another variable, boxed, or stored in a field, array or closure.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
object boxed = builder; // NAM1028: copy
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Append(1);
```

Keep one local builder per method.
