# NAM1040: Native workspace parameter must be a scoped read-only borrow

Severity: error. A workspace parameter is declared by value, `ref`, `out` or without `scoped in`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static int Peek(NativeWorkspace<int> workspace) => // NAM1040: by-value parameter
        workspace.Read(static view => view[0]);
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static int Peek(scoped in NativeWorkspace<int> workspace) =>
        workspace.Read(static view => view[0]);
}
```

Do not keep the borrowed workspace or its state beyond the helper.
Related: [NAM1036](NAM1036.md).
