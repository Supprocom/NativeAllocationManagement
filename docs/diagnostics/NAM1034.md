# NAM1034: Native builder completion requires a typed transfer destination

Severity: error. The result of `Complete` is discarded, widened to another type, or stored in a field or property.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Complete(); // NAM1034: result discarded
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
using NativeTransfer<int> data = builder.Complete();
```

Assign the result to a `NativeTransfer<T>` local, or return it.
