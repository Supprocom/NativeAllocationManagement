# NAM1031: Native builder ownership must end

Severity: error. A builder is neither completed nor disposed on some path out of its scope.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

NativeBuilder<int> builder = new(); // NAM1031: never completed or disposed
builder.Append(1);
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Append(1);
```

A `using` declaration ends the builder on every path.
Related: [NAM1032](NAM1032.md).
