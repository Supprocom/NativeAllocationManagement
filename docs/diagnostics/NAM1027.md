# NAM1027: Transfer parameter must own its value

Severity: error. A `NativeTransfer<T>` parameter is declared `in`, `ref` or `out`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static void Consume(in NativeTransfer<int> transfer) => transfer.Dispose(); // NAM1027: `in` parameter
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static void Consume(NativeTransfer<int> transfer) => transfer.Dispose();
}
```

Take the transfer by value: the callee then owns it and must dispose or move it.
