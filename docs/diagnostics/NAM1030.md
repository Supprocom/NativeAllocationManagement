# NAM1030: Native builder completion requires active ownership

Severity: error. `Complete` is called on a builder that is already completed or disposed.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
using NativeTransfer<int> first = builder.Complete();
using NativeTransfer<int> second = builder.Complete(); // NAM1030: second Complete
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
using NativeTransfer<int> data = builder.Complete();
```

Complete a builder once.
