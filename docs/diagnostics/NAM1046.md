# NAM1046: Native builder write state requires direct authority

Severity: error. A stateful `Write` uses a capturing, indirect, async or iterator callback; copies the state; or uses a state type that holds a NAM owner.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
WriteState state = new(11);
int extra = 5;
builder.Write(1, in state, (scoped NativeBuilderWriter<int> writer, scoped in WriteState current) =>
{
    writer.AsSpan()[0] = current.Value + extra; // NAM1046: capturing callback
    writer.Commit(1);
});

public readonly record struct WriteState(int Value);
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
WriteState state = new(11);
builder.Write(1, in state, static (scoped NativeBuilderWriter<int> writer, scoped in WriteState current) =>
{
    writer.AsSpan()[0] = current.Value;
    writer.Commit(1);
});

public readonly record struct WriteState(int Value);
```

A field typed `object`, `dynamic`, an interface, a delegate, a pointer or a type parameter also counts as holding an owner, at any depth. Pass plain data as `scoped in` state to one static callback.
Related: [NAM1045](NAM1045.md), [NAM1028](NAM1028.md).
