# NAM1006: Region construction must be lexical

Severity: error. A `NativeRegion` is not the direct resource of a `using`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeRegion region = new();
        Local<int> values = region.Lease<int>(4, 0);
        values.Access(static view => view[0] = 1);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeRegion region = new();
        Local<int> values = region.Lease<int>(4, 0);
        values.Access(static view => view[0] = 1);
    }
}
```

A region cannot be stored, passed on or built inside a helper; declare it with `using` in the method that uses it. A code fix is offered.
