# NAM1041: Native builder write view cannot escape

Severity: error. The span from `writer.AsSpan()` inside a `NativeBuilder<T>.Write` callback is passed to an ordinary method, stored, returned or captured.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Write(2, static writer =>
{
    Retain(writer.AsSpan()); // NAM1041: span leaves the callback
    writer.Commit(2);
});

static void Retain(Span<int> values) => _ = values.Length;
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Write(2, static writer =>
{
    Span<int> values = writer.AsSpan();
    values[0] = 1;
    values[1] = 2;
    writer.Commit(2);
});
```

The span points into storage that moves when the builder grows and is freed when it is disposed. To use a helper, pass the writer as `scoped ref NativeBuilderWriter<T>` and take the span there.
Related: [NAM1042](NAM1042.md).
