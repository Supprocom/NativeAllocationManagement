# NAM1042: Native builder write authority must remain direct

Severity: error. A writer from a `Write` callback is copied, passed by value, or the callback reaches `Write` through a stored delegate.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Write(1, static writer =>
{
    NativeBuilderWriter<int> alias = writer; // NAM1042: second handle to the writer
    alias.Commit(0);
});
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Write(4, static writer => WriteWords(ref writer));

static void WriteWords(scoped ref NativeBuilderWriter<int> writer)
{
    Span<int> values = writer.AsSpan();
    values.Fill(7);
    writer.Commit(values.Length);
}
```

The writer must commit exactly once, which the analyzer can check only while the writer stays with its callback. Pass a lambda or method group straight to `Write`, and forward the writer as `scoped ref`.
