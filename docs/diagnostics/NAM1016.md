# NAM1016: Pooled value crosses an unknown call

Severity: error. A lease is passed to a method the analyzer cannot show to be non-retaining.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        Keep(lease);
    }

    static void Keep(Pooled<int> lease) { }
}
```

## Right

```csharp
using System;
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => Fill(view.AsSpan()));
    }

    static void Fill(Span<int> values) => values.Fill(1);
}
```

Pass the data instead: call the method inside `Access` or `Read` with a span or a copy.
