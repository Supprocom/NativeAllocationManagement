# NAM1047: Concurrent lease callback requires direct authority

Severity: error. Enabled by default.

## Cause

`ConcurrentPooled<T>.Process(length, in state, callback)` runs the callback while the
lease is held for that call. The analyzer proves the callback cannot keep the lease
view only when the callback is one static lambda or method group passed directly,
with all its data coming through the state argument. This rule reports a callback
that captures variables, is passed indirectly through a stored or computed delegate,
or is asynchronous or an iterator.

```csharp
int extra = 3;
int total = values.Process(1, in state, (view, current) =>
    view[0] + current.Offset + extra); // NAM1047: captures 'extra'
```

## Correction

Put the data the callback needs into the state and make the callback `static`:

```csharp
public readonly record struct ProcessState(int Offset);

ProcessState state = new(3);
int total = values.Process(1, in state, static (view, current) => view[0] + current.Offset);
```

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof.
Suppressing it does not make the reported code safe; the runtime still rejects
stale or concurrent use where it can detect it. No automatic code fix applies.
