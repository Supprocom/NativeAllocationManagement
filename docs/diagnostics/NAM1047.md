# NAM1047: Concurrent lease callback requires direct authority

Severity: error. The callback passed to `ConcurrentPooled<T>.Process(length, state, callback)` captures variables or is passed through a stored or computed delegate.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int extra = 3;
int total = values.Process(1, 0, (view, state) => view[0] + state + extra); // NAM1047: captures extra
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int total = values.Process(1, 3, static (view, state) => view[0] + state);
```

Put what the callback needs into the state and make the callback `static`.
Related: [NAM1048](NAM1048.md), [NAM1049](NAM1049.md).
