# NAM1015: Deterministic field pool requires disposal

Severity: error. A field holds a pool created with `NativeMemoryReturn.Free`, but the containing type has no `Dispose` that disposes that field.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

sealed class Example
{
    readonly NativeConcurrentPool<int> _pool = new(returnMemoryOnDispose: NativeMemoryReturn.Free);
}
```

## Right

```csharp
using System;
using Supprocom.NativeAllocationManagement;

sealed class Example : IDisposable
{
    readonly NativeConcurrentPool<int> _pool = new(returnMemoryOnDispose: NativeMemoryReturn.Free);

    public void Dispose() => _pool.Dispose();
}
```

Implement `IDisposable` on the containing type and dispose the field there.
