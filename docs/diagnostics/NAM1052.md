# NAM1052: Owner memory is used after its storage ended

Severity: error. Enabled by default.

## Cause

`AsMemory()` on a `NativeTransfer<T>`, `NativeShared<T>` or `ConcurrentPooled<T>` returns a
`Memory<T>` (`ReadOnlyMemory<T>` for a shared payload) over the owner's native storage. The memory
is valid only while that owner is. This rule reports a memory, or a slice of one, used after its
owner was disposed, moved, or consumed by `NativeShared<T>.Create`.

```csharp
NativeTransfer<byte> buffer = NativeTransfer<byte>.CreateUninitialized(4096);
Memory<byte> memory = buffer.AsMemory();
buffer.Dispose();
int read = await stream.ReadAsync(memory); // NAM1052: the storage was returned
```

At run time the same mistake throws `ObjectDisposedException` when the memory's `Span` is read or
when it is pinned. The rule finds it before the program runs.

## Correction

Finish the operation before the owner ends, and keep the owner alive across the await:

```csharp
using NativeTransfer<byte> buffer = NativeTransfer<byte>.CreateUninitialized(4096);
int read = await stream.ReadAsync(buffer.AsMemory());
```

After a `Move`, take the memory from the new owner:

```csharp
NativeTransfer<byte>? source = NativeTransfer<byte>.CreateUninitialized(4096);
NativeTransfer<byte> owner = NativeTransfer<byte>.Move(ref source);
Memory<byte> memory = owner.AsMemory();
```

## What the rule can and cannot see

The rule reports a memory only when it can trace the memory to an owner's `AsMemory()` in the same
method. A memory passed to another method, stored in a field or returned is not followed.
Suppressing the rule does not make the reported code safe. No automatic code fix applies.
