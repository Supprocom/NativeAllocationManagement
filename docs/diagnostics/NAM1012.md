# NAM1012: Region-local value escapes its region

Severity: error. A region value is assigned or returned to a destination that outlives the region.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run(out Local<int> sink)
    {
        using NativeRegion region = new();
        sink = region.Lease<int>(4, 0);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static int Run()
    {
        using NativeRegion region = new();
        Local<int> values = region.Lease<int>(4, 0);
        return values.Read(static view => view[0]);
    }
}
```

Copy what you need into managed data before the region ends; `Read` returns a managed result. See also [NAM1051](NAM1051.md).
