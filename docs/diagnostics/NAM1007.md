# NAM1007: Native return has live generation state

Severity: error. `Reset` or a return ends the owner's generation while a lease from it is still live.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        ArenaLease<int> values = arena.Scratch<int>(4, 0);
        values.Access(static view => view[0] = 1);
        arena.Reset();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        arena.Reset();

        ArenaLease<int> values = arena.Scratch<int>(4, 0);
        values.Access(static view => view[0] = 1);
    }
}
```

A variable is live until its scope ends, even after its last use. Reset before you acquire the lease. Using the lease afterwards also reports [NAM1004](NAM1004.md).
