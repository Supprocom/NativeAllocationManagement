# NAM1023: Transfer move requires active ownership

Severity: error. `NativeTransfer<T>.Move` is called on a source that no longer holds ownership.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int>? source = NativeTransfer<int>.Create(4, 0);
        using NativeTransfer<int> first = NativeTransfer<int>.Move(ref source);
        using NativeTransfer<int> second = NativeTransfer<int>.Move(ref source);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int>? source = NativeTransfer<int>.Create(4, 0);
        using NativeTransfer<int> first = NativeTransfer<int>.Move(ref source);
    }
}
```

Move each source once, and not from a `using` variable.
