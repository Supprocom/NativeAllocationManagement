# NAM1002: Owner-derived handle cannot be copied

Severity: error. A lease is copied to another variable.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        Pooled<int> alias = lease;
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => view[0] = 1);
    }
}
```

Work on the lease where it was acquired, through `Access` or `Read`. See also [NAM1013](NAM1013.md).
