# NAM1039: Native workspace acquisition requires one proven owner

Severity: error. A workspace is created anywhere other than a local or a private readonly field of a sealed `IDisposable` class, for example a static field.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Cache
{
    static readonly NativeWorkspace<int> Shared = new(preLease: 16); // NAM1039: static field
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

sealed class Worker : IDisposable
{
    readonly NativeWorkspace<int> _workspace = new(preLease: 16);

    public void Dispose() => _workspace.Dispose();
}
```

A private readonly field is accepted when the sealed owner disposes it, as in the fix.
