# NAM1029: Inactive native builder cannot be used

Severity: error. A builder is used after `Complete` or `Dispose`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
using NativeTransfer<int> data = builder.Complete();
builder.Append(1); // NAM1029: used after Complete
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Append(1);
using NativeTransfer<int> data = builder.Complete();
```

Do all appends before `Complete`. The runtime throws `InvalidOperationException` on a completed builder.
Related: [NAM1030](NAM1030.md).
