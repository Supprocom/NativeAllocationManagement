# NAM1024: Native transfer view cannot escape

Severity: error. A callback view is passed to a method that may keep it.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
        transfer.Access(static view => Keep(view));
    }

    static void Keep(NativeLeaseView<int> view) { }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
        transfer.Access(static view => Use(view));
    }

    static void Use(scoped NativeLeaseView<int> view) { }
}
```

A view lives only inside its `Access`, `Read` or initializer callback. Pass it to methods whose parameter is `scoped`.
