# NAM1003: Native ownership must end before lexical exit

Severity: error. A pooled lease is still active on some path out of its scope.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => view[0] = 1);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => view[0] = 1);
    }
}
```

A `using` declaration disposes the lease on every path, including exceptions. See also [NAM1025](NAM1025.md) for transfers.
