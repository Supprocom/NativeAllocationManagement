# NAM1036: Native workspace ownership cannot be copied

Severity: error. A `NativeWorkspace<T>` is copied to another variable or boxed.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeWorkspace<int> workspace = new(preLease: 8);
object boxed = workspace; // NAM1036: copy
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeWorkspace<int> workspace = new(preLease: 8);
int length = workspace.Length;
```

Keep one owner. Helpers borrow it as `scoped in NativeWorkspace<T>` ([NAM1040](NAM1040.md)).
Related: [NAM1038](NAM1038.md), [NAM1039](NAM1039.md), [NAM1040](NAM1040.md).
