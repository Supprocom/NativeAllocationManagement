# NAM1032: Native builder acquisition requires one local owner

Severity: error. A builder is not created straight into a local: it is stored in a field, returned, passed as an argument or discarded.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Cache
{
    static readonly NativeBuilder<int> Shared = new(); // NAM1032: field
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
```

Create the builder in the method that completes or disposes it.
Related: [NAM1028](NAM1028.md), [NAM1033](NAM1033.md).
