# NAM1022: Inactive transfer cannot be used

Severity: error. A transfer is used after it was disposed or moved from.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
        transfer.Dispose();
        _ = transfer.Length;
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
        _ = transfer.Length;
    }
}
```

Use the transfer only while it is active; after `Move`, use the destination.
