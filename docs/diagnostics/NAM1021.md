# NAM1021: Transfer ownership cannot be copied

Severity: error. A `NativeTransfer<T>` is assigned to a second variable.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
        NativeTransfer<int> alias = transfer;
        alias.Dispose();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int>? source = NativeTransfer<int>.Create(4, 0);
        using NativeTransfer<int> owner = NativeTransfer<int>.Move(ref source);
    }
}
```

Hand ownership over with `NativeTransfer<T>.Move(ref source)`. For shared ownership use the share operations on `NativeShared<T>`.
