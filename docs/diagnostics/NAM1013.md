# NAM1013: Pooled value escapes its owner

Severity: error. A pooled lease or its span is stored where the owner's scope does not control it.

## Wrong

```csharp
using System;
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        Span<int> span = pool.Rent(4, 0).AsSpan();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => view[0] = 1);
    }
}
```

Keep the lease in a `using` variable and work through `Access` or `Read`.
