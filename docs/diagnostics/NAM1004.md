# NAM1004: Native value belongs to a returned generation

Severity: error. A lease is used after it was disposed, its owner was reset or returned, or it was moved from.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeConcurrentPool<int> pool = new();
        ConcurrentPooled<int> lease = pool.Rent(4, 0);
        lease.Dispose();
        lease.Clear();
        pool.Dispose();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeConcurrentPool<int> pool = new();
        ConcurrentPooled<int> lease = pool.Rent(4, 0);
        lease.Clear();
        lease.Dispose();
        pool.Dispose();
    }
}
```

Acquiring again does not revive the old value; use the new lease. After `Pooled<T>.Move`, use the destination. The same applies to the output of a refused `TryRent`.
