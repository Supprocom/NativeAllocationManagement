# NAM1037: Native workspace operation requires active authority

Severity: error. A workspace is used after `Dispose`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

NativeWorkspace<int> workspace = new(preLease: 8);
workspace.Dispose();
int length = workspace.Length; // NAM1037: used after Dispose
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeWorkspace<int> workspace = new(preLease: 8);
int length = workspace.Length;
```

A new workspace is a new allocation; create one instead of reusing the disposed one.
Related: [NAM1038](NAM1038.md).
