# NAM1049: Concurrent lease state cannot escape

Severity: error. Enabled by default.

## Cause

The state passed to a concurrent lease's `Process` call is lent to the callback for
that call only. This rule reports state that the callback aliases, stores in a field,
boxes, returns or forwards to a method that could keep it.

```csharp
static object? s_retained;

int first = values.Process(1, in state, static (view, current) =>
{
    s_retained = current; // NAM1049: boxed into a static field
    return view[0];
});
```

## Correction

Use the state inside the callback and return a plain result:

```csharp
public readonly record struct ProcessState(int Offset);

ProcessState state = new(3);
int total = values.Process(1, in state, static (view, current) => view[0] + current.Offset);
```

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof.
Suppressing it does not make the reported code safe; the runtime still rejects
stale or concurrent use where it can detect it. No automatic code fix applies.
