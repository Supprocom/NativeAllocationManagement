# NAM1049: Concurrent lease state cannot escape

Severity: error. State passed to a concurrent lease's `Process` is stored, boxed, returned or forwarded to a method that may keep it.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int total = values.Process(1, new ProcessState(3), static (view, state) =>
{
    Kept.Last = state; // NAM1049: stored
    return view[0];
});

public readonly record struct ProcessState(int Offset);

static class Kept
{
    public static object? Last;
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeConcurrentPool<int> pool = new();
using ConcurrentPooled<int> values = pool.Rent(1, 0);
int total = values.Process(1, new ProcessState(3), static (view, state) => view[0] + state.Offset);

public readonly record struct ProcessState(int Offset);
```

The state is lent for the call only.
