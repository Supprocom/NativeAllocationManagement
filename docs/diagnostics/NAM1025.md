# NAM1025: Transfer ownership must end

Severity: error. A transfer is still active when its scope ends.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeTransfer<int> transfer = NativeTransfer<int>.Create(4, 0);
    }
}
```

Dispose it, or move it to its new owner. A code fix is offered for simple cases. See also [NAM1003](NAM1003.md) for pooled leases.
