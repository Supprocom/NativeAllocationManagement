# NAM1038: Native workspace ownership must end

Severity: error. A workspace is not disposed on some path out of its scope.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

NativeWorkspace<int> workspace = new(preLease: 8); // NAM1038: never disposed
int capacity = workspace.Capacity;
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeWorkspace<int> workspace = new(preLease: 8);
int capacity = workspace.Capacity;
```

A `using` declaration disposes it on every path.
