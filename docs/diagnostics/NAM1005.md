# NAM1005: Using-owner lifecycle is automatic

Severity: error. An owner declared with `using` (not a `NativeRegion`) calls `Dispose`, `ReturnMemoryToNativeMemory`, `ReturnMemoryToGarbageCollector` or `LeaseFromMemory`. The `using` already disposes the owner at the end of the scope, so the analyzer rejects these calls.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        pool.Dispose();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativePool<int> pool = new(4);
        pool.Dispose();
    }
}
```

Either keep `using` and drop the call, or drop `using` and manage the owner yourself.
