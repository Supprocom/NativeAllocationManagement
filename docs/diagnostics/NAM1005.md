# NAM1005: Using-owner lifecycle is automatic

Severity: error. A `using` owner calls `Dispose`, `ReturnMemoryToGarbageCollector` or `LeaseFromMemory`, which its own cleanup already covers.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        pool.Dispose();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativePool<int> pool = new(4);
        pool.Dispose();
    }
}
```

Either keep `using` and drop the call, or drop `using` and manage the owner yourself.
