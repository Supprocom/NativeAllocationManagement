# NAM1050: Prepared lease requires a successful acquisition guard

Severity: error. A lease from a conditional acquisition (`TryRent`, `TryReserve`, `TryShare` and the prepared arena and group calls) is used without checking that the call returned `true`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativePreparedPool<int> pool = new(new NativePoolPreparation(2, 4, 2), null);
pool.TryRent(4, 42, out PreparedPooled<int> lease, out _);
lease.Dispose(); // NAM1050: result ignored
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativePreparedPool<int> pool = new(new NativePoolPreparation(2, 4, 2), null);
if (pool.TryRent(4, 42, out PreparedPooled<int> lease, out _))
{
    try
    {
        int first = lease.Read(static view => view[0]);
    }
    finally
    {
        lease.Dispose();
    }
}
```

A refused acquisition leaves a default value, not a lease. The unguarded code also reports [NAM1003](NAM1003.md) (or [NAM1025](NAM1025.md) for transfers). Use the result directly: `if (TryRent(...))`, or return early on `!TryRent(...)`.
Related: [NAM1003](NAM1003.md), [NAM1025](NAM1025.md).
