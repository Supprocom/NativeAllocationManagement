# NAM1011: Native value cannot cross an asynchronous boundary

Severity: error. A lease is held across `await` or `yield`.

## Wrong

```csharp
using System.Threading.Tasks;
using Supprocom.NativeAllocationManagement;

static class Example
{
    static async Task Run()
    {
        using NativeArena arena = new();
        ArenaLease<int> values = arena.Scratch<int>(4, 0);
        await Task.Yield();
        values.Access(static view => view[0] = 1);
    }
}
```

## Right

```csharp
using System.Threading.Tasks;
using Supprocom.NativeAllocationManagement;

static class Example
{
    static async Task Run()
    {
        Fill();
        await Task.Yield();
    }

    static void Fill()
    {
        using NativeArena arena = new();
        ArenaLease<int> values = arena.Scratch<int>(4, 0);
        values.Access(static view => view[0] = 1);
    }
}
```

Finish the work on the lease, in a separate method, before the `await`. Lease types are ref structs, so the compiler also reports CS4007.
