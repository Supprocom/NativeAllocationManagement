# NAM1011: Native value cannot cross an asynchronous boundary

Severity: error. Enabled by default.

## Cause and correction

Native lifetime authority must not silently survive an await or yield boundary. Complete the synchronous bounded operation before suspension. Where supported, explicitly move independently owned unique storage through a recognized handoff; source-visible arena/region borrows are not independently transferable owners.

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof. It
does not measure RSS, prove that an external provider follows its contract, or
make unsafe native storage safe when suppressed. Preserve capacity, initialization,
retention, thread and cleanup requirements when correcting the reported path.

Automatic correction is limited to the proven cases in the [code-fix contract](../analyzer-usability.md).
Other shapes require an explicit application ownership decision; no fix silently
adds sharing, copying, a larger cap or disabled analysis.
