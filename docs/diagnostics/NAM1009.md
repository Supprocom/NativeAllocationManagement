# NAM1009: Native owner lifecycle transition is invalid

Severity: error. An owner is called in a state that does not allow it, such as `Rent` after `Dispose`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativePool<int> pool = new(4);
        pool.Dispose();
        using Pooled<int> lease = pool.Rent(4, 0);
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativePool<int> pool = new(4);
        using (Pooled<int> lease = pool.Rent(4, 0))
        {
            lease.Clear();
        }
        pool.Dispose();
    }
}
```

Call the owner only while it is active; `LeaseFromMemory` is for an owner whose generation was returned.
