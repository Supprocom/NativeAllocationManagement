# NAM1017: Deferred pool return has live generation state

Severity: warning. `ReturnMemoryToGarbageCollector` ends the pool's generation while a lease is still live.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeConcurrentPool<int> pool = new();
        ConcurrentPooled<int> lease = pool.Rent(4, 0);
        pool.ReturnMemoryToGarbageCollector();
        pool.Dispose();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        NativeConcurrentPool<int> pool = new();
        ConcurrentPooled<int> lease = pool.Rent(4, 0);
        lease.Dispose();
        pool.ReturnMemoryToGarbageCollector();
        pool.Dispose();
    }
}
```

The lease is stale at once, even though the storage stays allocated until it is collected. Same cause as [NAM1007](NAM1007.md).
