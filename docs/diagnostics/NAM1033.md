# NAM1033: Native builder parameter is not permitted

Severity: error. A `NativeBuilder<T>` is passed to a method as a parameter.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static void Fill(NativeBuilder<int> builder) => builder.Append(1); // NAM1033: parameter
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Borrow(static (scoped ref NativeBuilderBorrow<int> borrow) => Helpers.Fill(ref borrow));

static class Helpers
{
    public static void Fill(scoped ref NativeBuilderBorrow<int> borrow) => borrow.Append(1);
}
```

Lend the builder to helpers with `Borrow`, which gives them a `scoped ref NativeBuilderBorrow<T>`, or complete it and pass the transfer. See [NAM1044](NAM1044.md).
Related: [NAM1028](NAM1028.md), [NAM1044](NAM1044.md).
