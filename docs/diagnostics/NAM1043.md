# NAM1043: Exclusive native builder borrow cannot escape

Severity: error. Enabled by default.

## Cause

`NativeBuilder<T>.Borrow` lends the builder to one callback, and the builder rejects
every other use until that callback returns. The `NativeBuilderBorrow<T>` view is
only valid during the callback. This rule reports a borrow that is returned, stored,
captured by a lambda or otherwise kept beyond the callback.

```csharp
static NativeBuilderBorrow<int> Keep(scoped ref NativeBuilderBorrow<int> borrow) =>
    borrow; // NAM1043: the borrow is returned
```

The same code also reports NAM1044, because returning the borrow uses it outside a
`scoped ref` parameter.

## Correction

Use the borrow inside the callback, and pass it to helpers only by `scoped ref`:

```csharp
builder.Borrow(static (scoped ref NativeBuilderBorrow<int> borrow) => AppendHeader(ref borrow));

static void AppendHeader(scoped ref NativeBuilderBorrow<int> borrow)
{
    borrow.Append(1);
    borrow.Append(2);
}
```

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof.
Suppressing it does not make the reported code safe; the runtime still rejects
stale or concurrent use where it can detect it. No automatic code fix applies.
