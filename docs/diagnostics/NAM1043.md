# NAM1043: Exclusive native builder borrow cannot escape

Severity: error. The `NativeBuilderBorrow<T>` from `NativeBuilder<T>.Borrow` is captured, stored or returned.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Borrow((scoped ref NativeBuilderBorrow<int> borrow) =>
{
    Action keep = () => _ = borrow.Count; // NAM1043: captured
    keep();
});
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Borrow(static (scoped ref NativeBuilderBorrow<int> borrow) =>
{
    int count = borrow.Count;
    borrow.Append(count);
});
```

The borrow is valid only during its callback. Returning or assigning it also reports [NAM1044](NAM1044.md); capturing it is also a C# compiler error (CS1628).
Related: [NAM1044](NAM1044.md).
