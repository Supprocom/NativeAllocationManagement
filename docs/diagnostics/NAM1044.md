# NAM1044: Exclusive native builder borrow requires scoped ref authority

Severity: error. Enabled by default.

## Cause

A `NativeBuilderBorrow<T>` must reach helpers as a `scoped ref` parameter, so that
the compiler and the analyzer can prove it does not outlive the `Borrow` callback.
This rule reports a borrow parameter declared by value, `in`, `out` or unscoped
`ref`; a borrow callback passed indirectly, for example through a stored delegate;
and use of the builder owner, or a nested `Borrow`, while a borrow is active.

```csharp
static void AppendHeader(NativeBuilderBorrow<int> borrow) => // NAM1044: by value
    borrow.Append(1);
```

## Correction

Declare borrow parameters as `scoped ref NativeBuilderBorrow<T>`, pass the borrow
callback directly, and use the borrow rather than the builder inside the callback:

```csharp
builder.Borrow(static (scoped ref NativeBuilderBorrow<int> borrow) => AppendHeader(ref borrow));

static void AppendHeader(scoped ref NativeBuilderBorrow<int> borrow)
{
    borrow.Append(1);
    borrow.Append(2);
}
```

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof.
Suppressing it does not make the reported code safe; the runtime still rejects
stale or concurrent use where it can detect it. No automatic code fix applies.
