# NAM1044: Exclusive native builder borrow requires scoped ref authority

Severity: error. A borrow parameter is declared by value, `in`, `out` or unscoped `ref`; or the callback is passed through a stored delegate; or the builder is used while a borrow is active.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Helpers
{
    static void AppendHeader(NativeBuilderBorrow<int> borrow) => borrow.Append(1); // NAM1044: by-value parameter
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
builder.Borrow(static (scoped ref NativeBuilderBorrow<int> borrow) => AppendHeader(ref borrow));

static void AppendHeader(scoped ref NativeBuilderBorrow<int> borrow) => borrow.Append(1);
```

While the `Borrow` callback runs, use the borrow, not the builder. The runtime throws `InvalidOperationException` for builder use during a borrow.
Related: [NAM1043](NAM1043.md), [NAM1033](NAM1033.md).
