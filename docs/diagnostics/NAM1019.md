# NAM1019: Ordinary native acquisition does not recycle scoped storage

Severity: warning. A `scoped` local is initialized by an ordinary acquisition such as `Scratch`.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        {
            scoped ArenaLease<int> values = arena.Scratch<int>(4, 0);
            values.Access(static view => view[0] = 1);
        }

        arena.RecycleScoped();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        {
            scoped ArenaLease<int> values = arena.ScratchScoped<int>(4, 0);
            values.Access(static view => view[0] = 1);
        }

        arena.RecycleScoped();
    }
}
```

`scoped` alone does not make the storage recyclable; use the `*Scoped` acquisition. See also [NAM1018](NAM1018.md).
