# NAM1018: Scoped acquisition must initialize a scoped local

Severity: error. A `*Scoped` acquisition result is not stored directly in a `scoped` local.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        {
            ArenaLease<int> values = arena.ScratchScoped<int>(4, 0);
            values.Access(static view => view[0] = 1);
        }

        arena.RecycleScoped();
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativeArena arena = new();
        {
            scoped ArenaLease<int> values = arena.ScratchScoped<int>(4, 0);
            values.Access(static view => view[0] = 1);
        }

        arena.RecycleScoped();
    }
}
```

Keep the acquisition and `RecycleScoped` in the same method. See also [NAM1019](NAM1019.md) and [NAM1020](NAM1020.md).
