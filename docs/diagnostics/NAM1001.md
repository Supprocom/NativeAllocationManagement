# NAM1001: Native owner alias is not permitted

Severity: error. A pool, arena or region is assigned to a second variable.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        NativePool<int> alias = pool;
    }
}
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

static class Example
{
    static void Run()
    {
        using NativePool<int> pool = new(4);
        using Pooled<int> lease = pool.Rent(4, 0);
        lease.Access(static view => view[0] = 1);
    }
}
```

An owner has one binding. Use that binding for every call; a field that holds an owner is covered by [NAM1015](NAM1015.md).
