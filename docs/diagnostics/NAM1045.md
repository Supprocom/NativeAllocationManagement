# NAM1045: Native builder write state cannot escape

Severity: error. State passed to `NativeBuilder<T>.Write(count, in state, callback)` is captured by a nested callback, stored, boxed or forwarded to a method that may keep it.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
WriteState state = new(11);
builder.Write(1, in state, Capture);

static void Capture(scoped NativeBuilderWriter<int> writer, scoped in WriteState state)
{
    Func<int> keep = () => state.Value; // NAM1045: captured
    writer.Commit(0);
}

public readonly record struct WriteState(int Value);
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeBuilder<int> builder = new();
WriteState state = new(11);
builder.Write(1, in state, WriteValue);

static void WriteValue(scoped NativeBuilderWriter<int> writer, scoped in WriteState state)
{
    writer.AsSpan()[0] = state.Value;
    writer.Commit(1);
}

public readonly record struct WriteState(int Value);
```

The state is only lent for the call. Storing or passing it on also reports [NAM1046](NAM1046.md); capturing it is also a C# compiler error (CS1628).
Related: [NAM1046](NAM1046.md).
