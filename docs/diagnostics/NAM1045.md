# NAM1045: Native builder write state cannot escape

Severity: error. Enabled by default.

## Cause

`NativeBuilder<T>.Write(count, in state, callback)` passes caller state to the write
callback by reference so that the callback needs no closure. The state belongs to the
caller and is only lent for the duration of the callback. This rule reports state
that is stored in a field, returned, boxed, captured or otherwise kept beyond the
callback.

```csharp
static WriteState s_last;

static void Remember(scoped NativeBuilderWriter<int> writer, scoped in WriteState state)
{
    s_last = state; // NAM1045: the state outlives the callback
    writer.Commit(0);
}
```

The same assignment also reports NAM1046, because it copies the state.

## Correction

Read what the callback needs from the state and keep anything that must outlive the
call in the caller's own variables:

```csharp
public readonly record struct WriteState(int Value);

WriteState state = new(11);
builder.Write(1, in state, WriteValue);

static void WriteValue(scoped NativeBuilderWriter<int> writer, scoped in WriteState state)
{
    writer.AsSpan()[0] = state.Value;
    writer.Commit(1);
}
```

## Ownership and memory constraints

This rule uses authenticated NAM symbols and source-visible lifetime proof.
Suppressing it does not make the reported code safe; the runtime still rejects
stale or concurrent use where it can detect it. No automatic code fix applies.
