# NAM1035: NativeRegion scope has a managed allocation

Severity: warning. Code inside a `NativeRegion` scope allocates on the managed heap.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

using NativeRegion region = new();
int[] scratch = new int[16]; // NAM1035: managed array
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeRegion region = new();
Span<int> scratch = region.Lease<int>(16, 0).AsSpan();
```

Reported for arrays, `new` of classes, closures, boxing, string concatenation and interpolation, collection expressions, `params` arrays, and async or iterator methods. The message names the allocation and where it comes from; move it out of the scope or use region storage.
Related: [NAM1006](NAM1006.md), [NAM1012](NAM1012.md).
