# NAM1026: Transfer acquisition requires a local source

Severity: error. A native transfer is created without a local variable to own it: the result is discarded or assigned straight to a field.

## Wrong

```csharp
using Supprocom.NativeAllocationManagement;

_ = NativeTransfer<int>.Create(4, 0); // NAM1026: discarded
```

## Right

```csharp
using Supprocom.NativeAllocationManagement;

using NativeTransfer<int> data = NativeTransfer<int>.Create(4, 0);
```

To keep a transfer in a field, create it into a local first, then move it with `NativeTransfer<T>.Move`. The same rule covers other ownership-producing calls whose result is discarded or stored, such as `TryReserve`.
Related: [NAM1021](NAM1021.md), [NAM1025](NAM1025.md), [NAM1034](NAM1034.md).
